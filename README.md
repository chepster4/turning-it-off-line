One funny line a hopeless tech support agent gives a desperate customer — an entry for the [make.fun bounty "Have You Tried Turning It Off?"](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The line

> I know you've already tried turning it off and on again. Let's try it once more, but this time with feeling.

The customer has clearly been through this already, and the agent's only escalation is vibes.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the line above to `/output/entry.txt`. The program is fully deterministic: every run produces the exact same bytes.

## Run

```sh
node main.ts
```

The line is written to `/output/entry.txt` — a single line of 108 characters, UTF-8, with no trailing newline.
